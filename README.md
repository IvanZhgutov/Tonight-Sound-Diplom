# Tonight Sound — студия звукозаписи

Космически-синий dark mode, глассморфизм, React.

## Стек
- **React 18** + Vite
- **react-router-dom** — страницы: /, /booking, /plugins, /login, /register, /profile, /admin
- **Framer Motion** — переходы страниц, stagger-карточки, анимации календаря и форм
- **Zustand** — состояние (auth, записи, каталог); в localStorage живут только
  черновик формы записи и кэш пользователя
- **Axios** — клиент API с интерцепторами (src/api/client.js):
  Bearer-токен подставляется в каждый запрос, 401 автоматически разлогинивает

## Запуск
```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # продакшен-сборка в dist/
```

Адрес API задаётся в `.env`: `VITE_API_URL=http://localhost:8000/api`
(бэкенд — соседний проект tonight-sound-api на Laravel 12, должен быть запущен).

## Админ-панель
Вход на /login учёткой из сидера бэкенда:
- email: `admin@tonightsound.studio`
- пароль: `admin123`

В админке: счётчики с /admin/stats, подтверждение/отклонение заявок,
обработка запросов плагинов («Добавлен» → тег «Новинка» в общем списке).

```
src/

  store/          # authStore, bookingStore, pluginStore (Zustand)
  general/        # constants.js, utils.js
  styles/         # index.css
```

## Что работает
- Запись: день выбирается в недельном виде или в календаре (после выбора
  календарь сворачивается; если день дальше недели — неделя начинается с него);
  время — мультивыбор часов 00:00–23:00 (3 ряда, дальше скролл); Telegram ID.
- Черновик формы хранится в bookingStore — выбор не теряется после
  ухода на /login или перезагрузки страницы.
- Без авторизации кнопка «Подтвердить запись» disabled с подсказкой войти.
- Профиль (/profile): записи пользователя, отмена, статусы, кнопка «Выйти».
- Плагины: категории-аккордеоны + живой поиск (раскрывает совпадения),
  запрошенный плагин появляется с тегом «Скоро», после одобрения админом — «Новинка».
- Мобильный адаптив: бургер-меню, перестроенные сетки и панели.

## Интеграция с API
- Услуги, плагины, записи и занятость слотов приходят с бэкенда —
  моки удалены (занятость больше не имитируется хэшем).
- При создании записи бэкенд проверяет конфликт часов; если слоты заняли,
  пока пользователь думал, — фронт показывает ошибку, перезапрашивает
  занятость и сбрасывает выбор.
- Сессия: токен в localStorage (`ts-token`), при старте приложения
  выполняется GET /auth/me; защищённые роуты ждут окончания проверки,
  чтобы не редиректить ложно.
- Отмена записи — оптимистичная, с откатом при ошибке сервера.

## Фото оборудования
Карточки на главной готовы под фотографии: положи файлы в src/assets
и укажи их в поле img в EQUIPMENT (general/constants.js) — заглушка
заменится автоматически.
